Application Help

Archaeoscapes is a landscape viewer for exploring monuments in the physical terrain in which they sit throughout the island of Ireland.

The application is intended to help show selected and relational monument groups in context: for example by monument class, era, likely purpose, spatial association, or other categorised relationships.

Top-Left View Controls

These controls manage the screen layout, saved views, help, and the selected-site orbit. They sit on the view itself so they remain available while working in the landscape.

Show/Hide sidebarExpands or collapses the sidebar to give more room to the landscape.
Hide ControlsReduces the interface for clean screen captures.
FullscreenRequests browser fullscreen where supported, useful on phones where the address bar consumes view height.
Save ViewStores the current view, selected site, visible markers, labels, ranges, and UI state.
Copy View URLCopies a shareable link for the current view state.
HelpOpens this help page over the view area.
Orbit selected siteRuns one smooth 360 degree orbit around the selected site.

Top-Right Display Options

These buttons decide what is shown on top of the terrain. The marker modes are mutually exclusive: selecting one monument mode turns the others off so the view has one clear meaning.

Reset viewReturns the camera towards the selected site and default viewing angle.
Show NotesShows notes for the active label. Click a label to make it active; close notes or turn this off to hide the notes pane.
Show LegendShows the icon legend for the currently visible monument marker categories.
Relational Monuments of TypeShows nearby monuments of the same selected type, within the configured Type range.
All Relational MonumentsShows nearby monuments from the enabled relational monument classes, within the configured All relational range.
Show All MonumentsShows all monument markers available in the current query area. It shows markers first, not labels.
Show All LabelsAdds labels only for markers that are already visible. If no marker mode is active, this turns off because there is nothing to label.

Notes, Links, and Details

The Notes panel appears when Notes is enabled and a label is active. The first line identifies the active monument; the scroll area contains notes and optional detail fields.

Open in Google MapsOpens the active monument location in Google Maps using its latitude and longitude.
Open in National Monuments ViewerOpens the official source record where a valid ROI or NI public record link is available.
ViewRecentres the display on the monument represented by the active notes panel.
DetailsExpands latitude, longitude, and the attribute table for the active monument.
Copy Lat/LonCopies the displayed latitude or longitude from the Details area and confirms with the green Copied message.
Notes backgroundToggles the translucent background behind notes for readability over bright imagery.
Close notesCloses the notes panel without removing the marker or label.

Legend Controls

The Legend explains the monument icons currently being used on the display. It updates as marker modes and monument classes change.

Legend backgroundToggles the translucent legend background for readability.
Close legendCloses the legend panel. Use Show Legend in the top-right toolbar to reopen it.

Movement Controls

The bottom-right movement controls move the camera through the landscape. Press and hold a control for smooth movement; on touch screens, one-finger drag rotates/pitches, two-finger drag pans, and pinch zooms.

Zoom inMoves the camera closer to the terrain and selected focus area.
Zoom outMoves the camera further away to show more surrounding landscape.
Move forwardMoves the focus point forward in the current viewing direction.
Move backMoves the focus point backwards from the current viewing direction.
Move leftMoves the focus point left across the terrain.
Move rightMoves the focus point right across the terrain.
Pitch downLowers the viewing angle toward the ground.
Pitch upRaises the viewing angle for a broader horizon and skyline view.
Rotate leftTurns the camera bearing counter-clockwise around the focus area.
Rotate rightTurns the camera bearing clockwise around the focus area.

Monument Icons, Markers, and Labels

Monument classes use repeatable geometric icons. The same class uses the same icon in the Monument Types list, Sites context, map markers, and Legend.

Markers

Markers are the small monument icons placed over the landscape. Click a marker once to show its label. Click the same marker again to remove that label.

Labels

Labels identify the monument. Click a label to make it active. If Notes is enabled, the notes panel then shows the active monument’s information.

Selection rule

There is no hidden reactivation state: marker click toggles the label, label click makes that label active, and removing an active label removes its notes.

Sidebar Usage

The sidebar is used from top to bottom: choose what kind of monument you want to examine, then choose the individual site, then optionally return to a saved view.

1. Choose a Monument Type

Open Monument Types and select a class such as passage tomb, wedge tomb, barrow, church, cross, or another enabled type. The application then queries the Ireland and Northern Ireland monument services and rebuilds the Sites list for that selected class.

2. Select a Site

Use the Sites cards to choose a monument. Each card gives the display name, SMR reference, and county. Selecting a site loads the terrain, places the selected marker, opens the selected label, and prepares the notes/detail tools for that monument.

3. Refine the Site List

Use Sort by County when you want the Sites list grouped geographically. This is useful when a monument type returns a long list across the island and you want to work through one county or border area at a time.

4. Return to Saved Views

Use Saved Views to reopen a named state. A saved view can restore the selected site, camera angle, visible marker modes, open labels, ranges, sidebar visibility, and control visibility.

Panel toggles

Use the caret or plus/minus button on a sidebar panel header to expand or collapse that panel. This keeps the sidebar manageable when long monument or site lists are loaded.

Configuration

Configuration changes what is available in the viewer and how the landscape is presented. These controls are collapsed by default so the normal site-selection workflow remains clear.

Saved Views

Turn stored views on when you want named views to persist in this browser. Use Purge Saved Views when you want to remove all stored view data from IndexedDB and start again. This affects this browser only.

Save Monument Selection

Leave this on if your chosen monument type set should survive a refresh. If the type list becomes too broad or too narrow, use Reset Defaults to restore the application’s default monument selection.

Presets

Tick or untick monument classes in Presets. Those choices directly control which classes appear in Monument Types, so this is where you build the working category set for the session.

Aerial Imagery

Select the imagery layer used on the terrain. Google Satellite, Esri Clarity, and Terrain can reveal different landscape evidence, from field boundaries to landform context.

Display Options

Use Display Visibility to change overlay opacity. Turn on notes, legend, related markers, all relational markers, all monuments, or all labels as needed. The Type range and All relational range sliders set the query radius from 0 to 20 km.

Terrain Controls

Use Height Exaggeration to increase or reduce relief. Choose Standard DEM Area for the normal footprint or Double DEM Area when a wider high-resolution terrain and imagery patch is needed.
