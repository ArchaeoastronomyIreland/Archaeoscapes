Application Help

Archaeoscapes is a landscape viewer for exploring monuments in the physical terrain in which they sit throughout the island of Ireland.

It supports monument selection, relational context, terrain and imagery comparison, saved views, panorama observation, viewshed horizons, astronomy overlays (Sun, Moon, paths, archaeolines, horizon compass), and horizon-line analysis for research and education.

Opens from Show Astronomy Tools while in FP view. Astronomy controls are not available in standard orbit view.

Horizon Line (Panorama)

In Panorama (first-person) view, Archaeoscapes computes a viewshed horizon from the observer position and draws it on the view. The line supports astronomy overlays and terrain clipping to the visible sky.

120 km scan

Quick, Hi-Res, and Super all scan out to 120 km. They differ in bearing count and DEM zoom: Quick (360 steps, Z11), Hi-Res (3600 steps, Z11), Super (3600 steps, Z12). Use Super for narrow distant peaks.

Calculation progress

When viewshed runs, a progress bar appears centred above the bottom readout pills. Quick starts automatically on entering Panorama; Hi Res and Super Res are on the Astronomy toolbar. The same bar appears while horizon relational monuments are fetched and matched to the skyline.

Line and fill

The horizon line follows the visible skyline. Nearby detail comes from the high-resolution terrain mesh; distant blockers from the viewshed profile.

Below-horizon sky

Sky below the horizon line is masked so it does not show through gaps in the terrain. Sun and Moon are clipped to the same horizon.

Markers

Small monument icons on the landscape. Click once to show a label. Click the same marker again to remove it.

Labels

Identify the monument. Click a label to make it active. With Notes enabled, the notes panel shows that monument’s information.

Selection rule

Marker click toggles the label; label click activates it; removing an active label clears its notes.

Sidebar Usage

Work top to bottom: location → saved view → monument type → site. Configuration and About sit below. The sidebar auto-collapses after loading a view.

View Location

Enter latitude and longitude under Location, then click View Location to load a standard camera view at any time (including from FP view). Loading a location enables all relational monuments in range. Fields accept decimal degrees (e.g. 53.490266, -7.5625666), comma decimals, optional N/S/E/W, and DMS (e.g. 53°29'24"N). You can paste lat, lon into the latitude field. Longitude may be entered as 0–360° and is normalised automatically.

Saved Views

Reopen named orbit or FP views stored in this browser. Restores site, camera/panorama state, marker modes, open labels, ranges, and UI visibility. FP views also restore date/time, archaeolines, and horizon relational settings. Use the toolbar to save, copy a URL, export, or import views.

Monument Types

Select a class to query ROI and NI monument services and populate the Sites list. Available classes come from Configuration → Presets.

Sites

Choose a monument card (name, SMR, county). Loads terrain, selected marker and label, notes tools, relational monuments, and collapses the sidebar.

Sort by County

Groups the Sites list geographically when working through long type lists county by county.

Panel toggles

Use the caret on each sidebar panel header to expand or collapse it. Configuration inner sections use the same collapsible pattern as Presets.

Configuration

Open Configuration in the sidebar. Inner sections are collapsed by default and share the same Presets-style layout. Expand any section with its caret.

Presets

Choose which monument classes appear in Monument Types.

Saved Views (storage)

Enable or disable IndexedDB stored views and purge all saved view data from this browser.

Save Monument Selection

Persist the current Monument Types checkbox set across sessions, or reset to defaults.

Aerial Imagery

Google Aerial, Esri Aerial Clarity (default), or Terrain relief. The Surface toolbar button toggles between Esri Clarity and Terrain.

Display Options

Overlay opacity, monument marker modes, label toggle, and Type / All relational range sliders (0–20 km).

Terrain Controls

Vertical exaggeration (0× = flat imagery surface) and Standard vs Double DEM area footprint.

Horizon Draw

Default horizon resolution for Configuration (Quick / Hi-Res / Super). All modes use a 120 km viewshed scan; see Horizon Line (Panorama) above.

Astronomy

Swiss Ephemeris (default) or Astronomy Engine; Swiss Ephemeris atmosphere (default on) applies refraction to Sun, Moon, paths, and archaeolines. UTC date/time with seconds; optional summertime display offset. Sun/Moon display scale; show Sun, Moon, and daily paths. Archaeoline types (equinox, solstice, cross-quarter, major/minor lunar) are enabled here; master toggles are on the Astronomy toolbar (rainbow and compass icons). Horizon compass is also available in Configuration.

Terrain Painting

Shader controls for height tint, relative height, contrast, hillshade, and distance grading on the terrain mesh.

Atmosphere & Display

Brightness, gamma, haze, desaturation, and fade distance for the rendered view. Stellarium export always uses a transparent sky.

Privacy & local data

No cookies are used. Archaeoscapes does not set or read cookies.

The only data stored on your device relates to saved views you choose to create. This is stored locally in your browser (IndexedDB) and is entirely under your control: save, reopen, export, import, disable storage, or purge all saved views from the toolbar or Configuration at any time.
